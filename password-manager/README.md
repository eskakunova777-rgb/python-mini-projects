# CLI Password Manager

Хранилище паролей в командной строке. Пароли шифруются (Fernet), мастер-пароль хранится в виде SHA-256 хэша, ключ шифрования — в локальном файле `.key`.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```bash
python password_manager.py
```

При первом запуске программа попросит придумать мастер-пароль. При следующих запусках — ввести его для входа.

## Команды

- `add` — добавить новую запись (название, логин, пароль — генерируется автоматически или вводится вручную)
- `get` — получить пароль по названию записи
- `list` — показать список всех записей (название и логин, без паролей)
- `delete` — удалить запись по названию
- `new` — сгенерировать пароль без сохранения (для быстрой проверки)
- `exit` — выйти

## Генератор паролей

По умолчанию — 16 символов, заглавные и строчные буквы, цифры, спецсимволы. Дополнительно можно исключить похожие символы (`0/O`, `l/I/1`), чтобы пароль было проще ввести вручную.

## Копирование пароля

Отдельной команды копирования в буфер нет — команда `get` печатает пароль в терминал, оттуда его можно выделить и скопировать вручную. Чтобы добавить копирование в буфер одной командой, можно подключить библиотеку `pyperclip` и вызвать `pyperclip.copy(password)` после расшифровки.

## Особенности безопасности

- Пароли никогда не хранятся в открытом виде — только в зашифрованном (Fernet) в `passwords.db`.
- Мастер-пароль хранится как SHA-256 хэш, не как исходный текст.
- Ключ шифрования (`.key`) — отдельный файл, без него зашифрованные записи не расшифровать.

**Если удалить файлы `.key` и `passwords.db`**, при следующем запуске приложение создаст их заново и сразу попросит ввести новый мастер-пароль. При этом база будет пустой — старые данные восстановить нельзя (это и есть смысл шифрования: без ключа данные бесполезны).
